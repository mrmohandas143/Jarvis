🤖 JARVIS - AI Voice Assistant

JARVIS is an intelligent AI-powered voice assistant developed using Python. It combines speech recognition, Google's Gemini AI, high-quality text-to-speech, web automation, and Raspberry Pi GPIO control to provide a smart interactive assistant capable of understanding voice commands, answering questions, controlling hardware, and performing daily tasks.


✨ Features

- 🎤 Voice Command Recognition
- 🧠 Google Gemini AI Integration
- 🗣️ Natural AI Voice Responses
- 🌐 Open Websites using Voice Commands
- 📖 Wikipedia Search
- ⏰ Time and Date Assistant
- 🔊 High-quality Neural Text-to-Speech
- 🎧 Wake Word Detection
- 🇮🇳 Indian English Speech Recognition
- ⚡ Raspberry Pi GPIO Hardware Control
- 🔧 Motor and Electromagnet Control
- 🤖 Interactive Conversational AI


🛠️ Technologies Used

🎙️ How It Works

1. Listens continuously for voice commands.
2. Converts speech into text.
3. Processes the command using predefined logic or Google Gemini AI.
4. Performs the requested task.
5. Responds with natural neural speech.

⚡ Hardware Integration

This project supports Raspberry Pi hardware using GPIOZero.

Supported components include:

- DC Motor
- Electromagnet
- PWM Motor Controller
- GPIO Output Devices

The assistant can execute hardware commands through voice interactions, making it suitable for robotics and automation projects.
